
# 📦 How to install

## Prerequisites

- Python 3.12+
- pip

## Steps

Clone the repository:

```bash
git clone https://github.com/CristianVeggian/Synaptomancer.git
cd Synaptomancer
```

Start a virtual environment and install dependences using **pip**

#### Windows

```powershell
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

#### Linux/MacOS

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## ▶️ Running the application 

Execute the _main.py_ file:

_Note: pay attention to the Python executable path. On some systems, it may be python3 instead of python._

```
python main.py
```
